# Historical Material

Status: Historical, non-normative.

This directory contains retained historical material that may explain how the project evolved.

Do not treat these files as current contracts. Maintained documentation lives in [../README.md](../README.md), and implementation remains the final authority for behavior.

Historical material may be deleted when its useful technical content has been consolidated into a canonical owner.

Old analysis and Codex prompt scaffolding was removed during an earlier
documentation cleanup. [Analysis_Package.md](../Analysis_Package.md) records the
former canonical-v2 analysis; it has since been superseded by
[Clock_Swing_Analysis.md](../Clock_Swing_Analysis.md). The maintained capture
owners are [Protocol_Wire_Contract.md](../Protocol_Wire_Contract.md) and
[Pendulum_Data_Record_Guide.md](../Pendulum_Data_Record_Guide.md).

Historical references also remain at their established paths under `Docs/`
and `Docs/Uno.R4.Deprecated/` so links and provenance are preserved. Their named
recordings, build sizes, test counts and pre-fix behaviour apply to those
snapshots. Local `Data/` inputs and generated figures may not be distributed.
Current operating instructions must link to a maintained owner instead of
treating an old investigation as the current implementation specification.
