# Historical module boundary

Retained historical analysis modules support regression checks. Their commands,
settings and output schemas are not translated by the maintained suite.

Use [Clock and swing analysis](../Clock_Swing_Analysis.md) for current analysis,
[the wire contract](../Protocol_Wire_Contract.md) for capture messages, and
[the data record guide](../Pendulum_Data_Record_Guide.md) for record semantics.
Historical investigations and their private recording evidence are excluded
from the public snapshot.
